
# 🏎️ Public Steward

**Public Steward** is a Formula 1 fan project that focuses on explaining and exploring the FIA rules, steward decisions, and racing regulations in a simplified, searchable, and interactive way.

🌐 Live Preview (once deployed): _Coming Soon_

---

## 📌 Features

- 📚 **FIA Rule Explorer** – Scrapes FIA.com and displays regulations & documents
- 🔍 **Searchable Interface** – Search for specific rules or keywords
- 🧠 **Interactive AI Assistant** (coming soon) – Ask questions about F1 rules
- 📰 **Race News & Team Updates** – Optional media module
- 💬 **Social Media Auto-Posting** – Share daily rule highlights

---

## 🛠️ Technologies Used

- **Frontend:** React.js (in `/client`)
- **Backend:** Flask (Python, in `/server`)
- **Web Scraping:** BeautifulSoup
- **Deployment:** Render / GitHub Pages / Netlify
